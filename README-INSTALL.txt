PENTING
PWA tidak di-install langsung dari file://. Upload semua isi folder ini ke hosting HTTPS, misalnya GitHub Pages. Setelah link situs aktif, buka link tersebut di Chrome Android lalu pilih Install app / Add to Home screen. Setelah pertama kali terbuka, service worker menyimpan app shell agar bisa dibuka offline.

Jangan upload ZIP sebagai satu file ke root Pages. Extract ZIP dahulu dan upload ISI foldernya. index.html harus berada di root repository/publishing folder.
